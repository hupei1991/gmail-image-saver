# Gmail 图片右键下载

Chrome Manifest V3 扩展，用于保存 Gmail 草稿及邮件里的图片。支持识别 Gmail 图片编辑覆盖层下方的图片，即使浏览器显示的是普通页面右键菜单，也能使用保存选项。

## 安装与更新

1. 在仓库页面点击 **Code → Download ZIP**，解压文件。
2. 打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 等草稿保存完毕，然后刷新 Gmail。
5. 在图片上右键，选择「保存 Gmail 图片…」，再选择保存位置。

更新文件后，在扩展管理页重新加载扩展，再刷新 Gmail。

## 功能

- 保留图片地址返回的原始文件字节及格式，不经过截图、重绘或压缩。
- 识别 Gmail 图片编辑覆盖层，避免依赖浏览器的「图片」菜单类型。
- 使用另存为窗口；同名文件采用不同名称。
- 扩展名称、右键菜单、弹窗和提示跟随 Chrome 界面语言，支持英文、简体中文、繁体中文，其他语言回退英文。
- 提供 16、32、48、128 像素透明 PNG 图标。
- 支持 JPG、PNG、GIF、WebP、BMP、AVIF、SVG、ICO、TIFF，图片大小上限 24 MB。

如果服务器在图片地址提供的是缩略图，保存的就是该缩略图，扩展无法恢复服务器未提供的更高分辨率文件。

## 隐私

扩展只在 `https://mail.google.com/*` 运行，只在点击保存菜单时读取所选图片。使用现有 Gmail 登录状态，不需要密码、API 密钥或 OAuth 设置。没有统计及第三方服务器；不扫描邮箱、不发送邮件、不修改草稿。扩展不会持久保存图片地址或图片数据，下载文件及下载记录由 Chrome 管理。

权限只有 `contextMenus`（添加菜单）和 `downloads`（下载到本机）。仓库中的测试数据为合成示例，不包含邮箱内容、截图、签名附件地址或用户专属配置。

## 限制与验证

需要 Chrome 109 或更高版本。暂不支持附件卡片、CSS 背景图片及超过 24 MB 的图片。跨域外部图片可能因服务器限制读取而失败。

菜单未出现时，请确认扩展已启用并刷新 Gmail。扩展图标出现 `!` 时，可打开弹窗查看错误。在空白处使用菜单会提示没有图片。下载完成情况以 Chrome 下载列表为准。

开发测试：安装 Node.js 22 或更新版本后运行 `npm test`。29 项自动化测试使用模拟 Chrome API，覆盖原始字节、覆盖层识别、响应验证、文件名、语言、弹窗及图标；真实浏览器安装及下载仍需手动验证。
